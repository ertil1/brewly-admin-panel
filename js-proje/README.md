# ☕ Brewly Admin Panel (Web Geliştirme JavaScript Projesi)

Bu proje, modern JavaScript teknikleri kullanılarak geliştirilmiş bir Kahve Siparişi ve Ürün Yönetim Sistemidir (CRUD uygulaması). Gelişmiş tasarım teknikleri, modüler dosya mimarisi ve Vanilla JS kullanılarak hazırlanmıştır.

## 🚀 Özellikler

* **CRUD İşlemleri:** Ürün Ekleme, Listeleme, Güncelleme ve Silme işlemleri.
* **Modern Mimarİ:** ES6 modülleri (ES Modules) ile Component, Page, Interface katmanları.
* **Kalıcı Veri (Persistence):** LocalStorage üzerinden veritabanı simülasyonu.
* **Premium Tasarım:** Glassmorphism (cam efekti), animasyonlu gradient arka plan ve gelişmiş CSS özellikleri.

## 📁 Dosya Yapısı

```text
├── index.html           # Ana sayfa iskeleti
├── style.css            # Özel Vanilla CSS (Glassmorphism & Animasyonlar)
├── App.js               # Uygulama Başlangıç Noktası
├── Components/
│   └── ProductCard.js   # Ürün listesi ve kart bileşenleri
├── Pages/
│   └── Dashboard.js     # Modal, form ve etkileşim yöneticisi
└── Interfaces/
    └── Store.js         # LocalStorage Veri Katmanı
```

## 🛠️ Kurulum ve Kullanım

Herhangi bir sunucu kurulumu gerektirmez. Uygulamayı denemek için:
1. Projeyi bilgisayarınıza indirin.
2. `index.html` dosyasını tarayıcınızda açmanız veya Live Server eklentisiyle çalıştırmanız yeterlidir.
3. Veya doğrudan Netlify linki üzerinden canlı projeyi test edebilirsiniz.
